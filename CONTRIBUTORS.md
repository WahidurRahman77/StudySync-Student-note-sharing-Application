# Contributors & Contribution Guidelines

Thank you for your interest in contributing to StudySync — Student Note Sharing Application.

## How to contribute
1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. Make your changes and test them locally.
4. Commit with clear, descriptive messages.
5. Open a pull request with a short summary and testing steps.

## Code style
- Use idiomatic Kotlin conventions.
- Keep UI logic separated from business logic where possible.
- Prefer clear class and function names.
- Keep credentials and secret keys out of source control.

## Reporting issues
Please report bugs or feature requests using the issue templates under `.github/ISSUE_TEMPLATE/`.

## Collaboration expectations
- Be respectful and constructive.
- Provide clear descriptions in PRs.
- Include screenshots or logs when reporting bugs.
- If a change is large or uncertain, open an issue first.

## Thanks
Your contributions help improve StudySync for students and academic communities.
